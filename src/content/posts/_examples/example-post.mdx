## Math

Inline math goes between single dollar signs: under serial scheduling the fourth client waits $4P + 3D$ for its first token, where $P$ is prefill time and $D$ is decode time.

Block math goes between `$$` lines:

$$
\text{TTFT}_k^{\text{serial}} = kP + (k-1)D, \qquad \text{TTFT}_k^{\text{batched}} \approx kP
$$

$$
\begin{aligned}
\text{throughput} &= \frac{\text{tokens generated}}{\text{wall-clock time}} \\
&\approx \frac{B}{S_1\left(1 + (m - 1)\frac{B - 1}{3}\right)}
\end{aligned}
$$

## Code

```python file=iteration_batching.py
while waiting or active:
    while waiting and len(active) < max_batch:
        manual_prefill(waiting.pop(0))  # [!code highlight]
    batched_decode_step(model, dims, active)
    active = [r for r in active if not r.done]
```

## Images

Put images in `src/assets/images/` and reference them with a relative or `@/` path, e.g. `![Alt text](@/assets/images/diagram.png)`. Astro optimizes them at build time.
